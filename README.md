# Galaxy Fusion — React Native (LinkedIn + GitHub for Individual Colleges)

**Galaxy Fusion** is a college-specific **Student–Student**, **Student–Faculty**, and **Student–College** collaboration network built on **React Native (Expo + TypeScript)** and **Supabase**.

---

## Three-Way Collaboration Architecture

1. **🤝 Student ↔ Student Collaboration (`Teammates` & `Campus Hub` Tabs)**
   - **Ask for Teammates Composer & Cards**: Broadcast teammate requests for hackathons (SIH), B.Tech projects, or startups specifying skills you have, missing skills needed, and open slots.
   - **Verified Peer Directory & Skill-Gap Matcher**: Search verified students within your college by skill or branch with compatibility match scores (`96% Match`), GitHub commit counts, and 1-tap team invites.
   - **Skill Groups & Live Chat**: Real-time squad messaging powered by Supabase Realtime (`group_messages`).

2. **🎓 Student ↔ Faculty Collaboration (`College & Labs` Tab)**
   - **Faculty Research Labs & Major Project Slots**: Professors post open Research Assistant (RA) slots, IEEE paper co-authorship opportunities, and SIH mentorship openings.
   - **1-Tap Lab Applications & Mentor Messaging**: Students apply directly with their verified GitHub repository portfolio and CGPA.

3. **🏛️ Student ↔ College Collaboration (`College & Labs` Tab)**
   - **Individual College Workspaces**: Switch between dedicated college instances (*GLA University Mathura*, *IET Lucknow (AKTU)*, *KIET Ghaziabad*, *AKGEC Ghaziabad*, *JSS Noida*).
   - **Official College T&P Drives, Internships & Seed Grants**: The Training & Placement Cell and Incubation Cell post Super Dream/Dream drives, paid campus ERP internships, and ₹50,000 startup grants with automatic Semester 1–8 CGPA eligibility checks.
   - **Student–College Townhall**: Students propose and upvote campus action items (like GitHub Issues) and track official responses (`Approved by Dean`, `In Progress`).
